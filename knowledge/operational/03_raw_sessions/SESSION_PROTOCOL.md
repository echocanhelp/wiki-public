# Session protocol

## Pre-flight
1. Confirm consent on file for talent (`08_consents/`)  
2. Send script PDF 48h prior  
3. Confirm mic: 48 kHz / 24-bit  

## Top of session
1. Record spoken consent if not yet taped  
2. Slate: project, chapter, date, language, narrator  
3. 30 s room tone  
4. 1-page level check (−12 to −6 dBFS peaks)

## During
- Work in section blocks  
- Log pickups: `pickup_log.csv` columns: chapter,timecode,reason,status  

## End
- Backup to two locations same day  
- Rename: `EN_Ch01_YYYYMMDD_raw.wav`
