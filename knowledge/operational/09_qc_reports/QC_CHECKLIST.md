# QC checklist (per language edition)

## Technical
- [ ] 48 kHz / 24-bit archive WAV present  
- [ ] Integrated loudness within target (−16 to −18 LUFS reference)  
- [ ] True peak ≤ −1.5 dBTP (or ACX ≤ −3 if that path)  
- [ ] No clipped samples  
- [ ] Head/tail silence 0.5–1.0 s  
- [ ] Mono or dual-mono consistent  

## Editorial
- [ ] Full proof-listen vs script  
- [ ] Names match pronunciation bible  
- [ ] No double takes / edits audible as jumps  
- [ ] Chapter titles correct  
- [ ] Second ear for 華語 / 台語  

## Metadata
- [ ] Track order matches CSV  
- [ ] ISRCs filled  
- [ ] Cover 3000×3000  
- [ ] Language tags correct
