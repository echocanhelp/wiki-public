2024-04-20 法廣
經過漫長而艱難的談判，美國國會眾議院週六(4月20日）終於通過對烏克蘭、以色列和台灣950億美元龐大對外援助法案，烏克蘭總統澤連斯基及歐盟和北約等各國一致對此表示歡迎。澤連斯基稱”法案將阻止戰爭蔓延，拯救成千上萬生命”，美國總統拜登也對眾院在”歷史性的會議上”通過關鍵的援烏法案表示歡迎。
法新社報道，在美國眾院周六通過美國向烏克蘭提供近610億美元的援助法案後，烏克蘭總統澤連斯基立即對此表示歡迎，澤連斯基在X 上發文感謝美國的議員們稱：“美國眾議院今天通過的拯救生命的法案將阻止戰爭蔓延，拯救成千上萬的生命，並將使我們兩國變得更加強大。”
作為烏克蘭最重要的支持者，美國總統拜登也在第一時間對眾院在”歷史性的會議上”通過關鍵的援烏法案表示歡迎。法案獲兩院通過後，將呈交總統拜登批准。
北約和歐盟 領導人週六也紛紛對美國眾議院批准備受期待的援烏法案表示歡迎。
北約秘書長斯托爾滕貝格表示，對美國眾議院批准重要的援烏新法案表示歡迎，他說，這表明(美國國會）兩黨對烏克蘭持續的支持。斯托爾滕貝格表示， “烏克蘭正在使用北約盟國提供的武器摧毀俄羅斯的作戰能力，此舉將加強歐洲和北美所有人的安全”。
歐盟委員會主席馮德萊恩及歐洲理事會主席米歇爾也對美國眾議院的投票結果表示歡迎。
歐洲理事會主席米歇爾在 X 上發文稱， “這向克里姆林宮發出了一個明確的信息：那些相信自由和《聯合國憲章》的人將繼續支持烏克蘭”；馮德萊恩在一份聲明中表示：“烏克蘭應該得到應對俄羅斯入侵的一切支持。現在我們呼籲美國參議院儘快投票，因為生命危在旦夕。跨大西洋盟友國家將團結一致支持自由和民主” 。
另外，德國外長貝爾博克表示，“對於烏克蘭和歐洲的安全來說這是一個充滿樂觀情緒的一天”。貝爾伯克表示，“美國援助烏克蘭的一個主要障礙已經消除，美國和歐洲站在自由一邊，反對普京的恐怖戰爭”。
美國參議院民主黨領袖舒默週六表示，參議院將儘快審議對外援助法案文本，最早可能在下周二進行。
共和黨控制的美國聯邦眾議院週六通過總值950億美元的對外援助法案，向烏克蘭、以色列和台灣提供安全援助，並強制TikTok脫離中國母公司字節跳動。
眾院週六以360票對58票通過表決的第1項法案，即”21世紀透過實力達成和平法案”（21st Century Peace through Strength Act），法案內容包括對伊朗的制裁、扣押凍結的俄羅斯主權資產，以及迫使短視頻平台TikTok脫離中國母公司字節跳動（ByteDance），否則將在美國面臨全國性禁令。TikTok在美國擁有約1.7億用戶。
隨後，眾院以385票對34票的投票結果，通過81億美元的”印太安全補充法案”（Indo-Pacific Security Supplemental bill），其中包括向台灣和其他主要盟友提供20億美元軍事資金、用以補充向台灣和區域夥伴提供的國防物資和服務的19億美元，以及用於抗衡中國的81億美元。
“烏克蘭安全補充撥款法案”（Ukraine Security Supplemental Appropriations Act）則以311票對112票過關，該法案將提供610億美元以協助烏克蘭和地區合作夥伴對抗俄羅斯。
最後，眾院以366票對58票通過”以色列安全補充法案”（Israel Security Supplemental bill），以向以色列提供264億美元援助。
上述4個法案獲眾院通過後將合並為1項修正案，並提交給參議院。
路透社報導，自民主黨主導的聯邦參議院通過類似措施以來，已過了2個多月。從民主黨籍總統拜登到聯邦參議院共和黨領袖麥康奈（Mitch McConnell）等領導人，一直在敦促陷入困境的共和黨籍眾院議長約翰遜將其提交投票。
聯邦參議院多數黨領袖舒默（Chuck Schumer）先前已承諾，一旦眾議院通過上述措施，民主黨佔多數的參議院將迅速行動。部分強硬派共和黨籍極右翼議員則警告，他們可能會因約翰遜推動這些法案而罷免他。
