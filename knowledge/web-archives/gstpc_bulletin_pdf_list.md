## Notes

The bulletin PDF listing page redirects to a Google Drive viewer. The page displays a QR code for downloading weekly bulletins in PDF format. The actual PDFs are binary files and cannot be scraped via r.jina.ai.

- **Title:** latest-bulletin.pdf - Google Drive
- **Content:** Google Drive viewer with sign-in prompt
- **Access:** QR code download via the GSTPC website; PDFs themselves are not text-scrapable
