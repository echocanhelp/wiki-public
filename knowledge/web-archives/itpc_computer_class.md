# 電腦教室

電腦教室簡介：

 使用電腦是現代人必備的基本生活技巧。 電腦能提供豐富的資訊，增加新知，包 括娛樂，醫療, 財經，社交等。 電腦能也能提高生活的品質和樂趣。為了幫助稍為年長的台灣同鄉學習使用電腦， 台灣基督長老教會開設了電腦教室，做非宗教性的社區服務。

電腦教室特點：

1.   台語說明解釋。 電腦科目的教課以台語為主，兼用中文與英語術語。
2.   小班教學。 每次上課學生在10人以內，強調現場的實際操作練習。
3.   教師及助教能隨時給予學習者直接的幫助，提高學習的信心和興趣，增強學習的效果。
4.   非營利性的社區服務。 學生不繳學費，只付低廉的報名講義費。

授課科目 (每一科目是5週或6週，每週上課一次，每次90分鐘)

 (A) PC電腦課程 -- PC是傳統型的電腦，現在仍是電腦市場及使用者的主流。我們的PC課程使用IE瀏覽器，Windows 7作業系統。 
1.   PC101 基本電腦技巧 (5週) -- 這一課程是為了沒有使用過電腦的人及非常不熟識PC的電腦 操作的人而設計的初級班。 這一課程也是其他 PC課程必需具備的基楚。這一課程包括簡介電腦 的硬體和軟體，認識桌面(desktop)和視窗(windows)，滑鼠的使用，Windows7的基本操作，及簡介 中文輸入法。課程偏重Internet的基本應用，瀏覽網頁，資訊搜尋，及電子郵件的使用。
2.   PC201 中文輸入法及檔案管理 (5週) -- 這一課程幫助你了解檔案和檔案夾的基本觀念和良好的 檔案管理技巧。這一課程幫助你利用電腦螢幕上的中文注音鍵盤來撰寫及輸入中文。
3.   PC205 Word (5週) -- 這一課程幫助你輕易的做有專業水準的文件撰寫和編輯。文字文件的編輯， 包括設定字型，大小，顏色等，並可插入相片，圖形，表格，及影音等各式物件。
4.   PC206 PowerPoint (5週) -- 這一課程的學習者需具有基本的電腦操作技巧，和有需要使用投影片 在大小聚會中放映，做有效的演講或分享資料內容。 這一課程幫助你輕易地用文字，相片圖形， 和影音等來製作有專業水準的簡報，以投影片slides的形式放映你的資訊。
5.   PC208 Picasa (5週) -- 幫助你將相機所拍攝的照片直接輸入電腦，組織和修飾相片，email相片， 操作 slideshows，及製作CD或DVD相片光碟片等。
6.   PC305 網站網頁之建設與維修 (6週) -- 這一課程是為有興趣於建造和維修網站 (Website) 的人 設。 網站可屬於個人或社團公司。 本班課程比較深入，使用網頁語言XHTML及CSS來設計 和製作網頁。課程也討論如何註冊網站，選用hosting company，及FTP等。

(B) iPad電腦課程 -- iPad 是最暢銷的平板電 (Tablet computer)，使用 iOS 7作業系統。 平板電腦 是 一種小型的，攜帶方便的電腦，主要以觸控輸入，可用手指觸控、書寫、縮放畫面等。 平板電 腦有優點和缺點，但是廣受一般非職業性大眾的歡迎，平板電腦的普及是一趨

 勢。 
1.   iPad101 iPad的基本功能和應用 (5週) -- 這一課程是為了從未用過iPad，或是雖用過iPad而仍有生 疏感的人而設計的 iPad 初級班。 這一課程幫助熟練iPad之基本操作： 認識 iPad 的按鈕和主畫面與 圖示，做重要的基本設定，各種基本操作手勢，及簡單介紹中文輸入法。 這一課程幫助你熟練重要 的 iPad 基本功能：用 Safari上網查資訊， 收發 E-mail 信件，到 APP Store 下載應用軟體，及簡單介紹拍照 相片和錄影 (Camera app) 及展示和分享相片(Photos app)。
2.   iPad201 相片的整理和修飾 (5週) – 深入的了解應用： (1)內建軟體 Camera和Photos的功能，

 (2)下載使用Photo及iPhoto 軟體來作應用廣泛的相片修飾和整理。

 - iPad205 應用軟體 (5週) –介紹不同軟體的使用，例如Dropbox，Notability，Skype，LINE，等等。
