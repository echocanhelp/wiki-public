# Web Archives

Scraped web content from Echopedia crawls and web archive captures.

## Purpose

Store raw scraped content before it's classified and potentially moved to the wiki.

## File Naming Conventions

```
[domain]-[page-type]-[date].md
```

Examples:
- `itpc.org-history-2026-06-06.md`
- `gstpc-bulletin-2020-07-26.md`
- `taiwan-center-about-2026-06-06.md`

## What Belongs Here

- Website crawls (official church sites, organization pages)
- Web archive captures
- Scraped articles or blog posts
- Any content that came from a web crawl

## Example Structure

```markdown
---
title: "Irvine Taiwanese Presbyterian Church History"
category: "web-archives"
source: "https://itpc.org/about/history"
crawled: "2026-06-06"
---

# Irvine Taiwanese Presbyterian Church History

[Scraped content here...]
```
