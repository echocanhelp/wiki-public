# 新館建館工程進度

台灣會館新館工程持續推進中，期待與社區共同見證這座全新文化地標的誕生。

February 5, 2026

![Image 8: Architecture](https://cdn.prod.website-files.com/68a69cbd7fc3be5050e05c9f/69844edabb11bbcd8b903782_%E6%9C%83%E9%A4%A8.png)

[![Image 9](https://cdn.prod.website-files.com/68a69cbd7fc3be5050e05c9f/6a5552832d529ae3dd86e434_2026-07%20TC%20Presentation.pptx.jpg)](https://drive.google.com/file/d/1PZ7kvV4tFvqI3FJjKBpQMO2xYQZdQXUJ/view?usp=drive_link)[![Image 10](https://cdn.prod.website-files.com/68a69cbd7fc3be5050e05c9f/6a555295b0f0101d1ee437f7_Construction01.png)](https://drive.google.com/file/d/1gbXIZq059OsdN4yDNRXXfPCXos_DjoVv/view?usp=drive_link)
大洛杉磯台灣會館新館建設工程目前正積極施工中。這座全新的台灣會館將配備更完善的現代化設施，為社區提供更寬敞、多功能的活動空間，滿足文化傳承、教育推廣及社區聚會等多元需求。

新館的興建是數千位鄉親共同的心願與努力。從規劃設計到動工建設，每一步都凝聚著社區的支持與期待。我們將持續透過網站及社群媒體更新工程進展，邀請大家一起關注、一起期待。

如果您希望為新館建設出一份力，歡迎聯繫會館辦公室了解捐款方式，與我們共同打造台美人社區的嶄新家園。
