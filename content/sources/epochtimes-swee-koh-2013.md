# 大紀元 2013-11-08 — 專訪許瑞慶（Swee Koh）

大紀元記者李曼美國休士頓採訪報導，2013-11-08。人物自述訪談（第一手自述、媒體載錄 → 頁面標籤用 alleged/sourced 時依自述性質標 `sourced（本人自述，媒體載錄）`）。

## 要點（帶日期）

- 大紀元稱：休士頓很多華人都認識的一位**業餘二胡演奏家**；在大型華裔活動常露面；〈二泉映月〉〈新婚別〉是其動人曲目；聽眾因他的二胡演奏認識他，「並走進他的地產生意中」——**地產經紀人 Swee Koh**。
- 自述：音樂相伴近三十年；出生於風景秀麗的農村；小時受姐姐（愛吹笛子）影響喜愛音樂；初中在**馬來西亞**學校華樂團任二胡演奏員；當時找專業二胡老師很難，靠演奏卡帶、樂譜自學互教，「可以說是自學成才」。
- 馬來西亞每年一次全國二胡比賽，邀請東南亞專業二胡演奏家當評委；賽後研討會/大師班當場向大師提問，演奏技巧大為提高。
- 「我來休士頓已有十五年了」（2013年時 → 約1993–94 抵休士頓，與 HCTMG 團員頁「1993 赴美」一致）。
- 地產之前是**工程師**；大學讀**工業工程系**；畢業後在建築公司工作十餘年，專業為**結構工程師**；「我天生就喜歡房子」。
- 閒暇常在各地做**慈善文化表演**；一些地產客人是透過音樂認識他。
- 論二胡：「二胡是表現力很強的楽器……當你人生際遇越多，閱歷越廣的時候，你的感受就越深。」
