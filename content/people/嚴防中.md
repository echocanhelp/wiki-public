## Fix rule (card-owned; the script change belongs to its own lane)

A candidate must die when the **longest token in its own truncation chain** starts with a
「嚴」-adverb verb (`嚴防`, `嚴查`, `嚴禁`, `嚴抓`, `嚴辦`, `嚴治`, `嚴打`, `嚴管`, `嚴懲`,
`嚴密`, `嚴格`, `嚴正`, `嚴詞`, `嚴加`) — the same shape as the existing prefix-chain rule, which
already kills a strict *prefix* of a known boilerplate phrase. Control set confirming the rule
does not suppress real 嚴 surnames: `嚴家其`, `嚴歌苓`, `嚴復`, `章孝嚴` all stay mintable.
