# Elder John Lai (賴永祥)

## Identity Snapshot
- **TAH English Name:** John Lai
- **漢名:** 賴永祥 · TAH 賴永祥長老
- **POJ / Tâi-lô (ZH Wikipedia):** Loā Éng-siông / Luā Íng-siông
- **Wiki file title (wedding scan):** John Young-hsiang Lai — not treated as TAH English Name
- **Born:** **1922-09-21** 日治臺南州新營郡後壁庄上茄苳（今後壁區嘉田村）— [生平](http://www.laijohn.com/life/biog.htm); ZH Wikipedia
- **Died:** **2024-06-07** 波士頓護理中心，101 歲（ZH Wikipedia）；林宜瑩《台灣教會公報》2024-06-08 作**享嵩壽 102** — both kept
- **Geography:** 後壁 → **1926** 基隆 → 臺北高校 / 東京帝大 → 臺大 → Harvard / Boston MA（TAH first US **1972**）
- **Core roles:** 圖書館學；臺大圖資系主任；哈佛燕京副館長；《中國圖書分類法》編修；《教會史話》；[[organizations/elder-john-lai-archives|史料庫]]
- **Not:** PCT sitting GA officer; not TAH staff; EN Wikipedia “John Lai” disambiguation hits are **other people**

Official biog: 父**盧明** 母**賴葉**；長男**從母姓賴**；弟**盧焜熙**. TAH Family: wife **劉慶理**; 子女 `--` — **no pages**.

TAH card: Vanderbilt / Boulder College. Official biog: **畢包地（Peabody）** MLS. Both kept.
