# LINE Kickoff Messages for TAHS Member Onboarding

Use these messages to start induction quickly and consistently in LINE.

## Standard kickoff (group)
@member Use tahs-member-onboarding for this new member. Start Echopedia onboarding and collect required profile details.

## Warm kickoff (group)
@member Welcome! We’re starting your TAHS onboarding. EchoHsu will help create your Echopedia member page and guide you through the needed details.

## Direct kickoff (DM)
Use tahs-member-onboarding for this new member from LINE. Start onboarding and draft their Echopedia page.

## Operator checklist before kickoff
1. Confirm chat/group is authorized for bot responses.
2. Include member display name and preferred Chinese + English naming if available.
3. Optionally include proposed title to speed assignment.
