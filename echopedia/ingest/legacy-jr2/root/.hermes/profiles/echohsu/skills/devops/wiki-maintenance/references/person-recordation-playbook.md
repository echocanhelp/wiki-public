# Person Recordation Playbook (Echopedia)

Use this when creating/upgrading `type: person` pages for TAHS/Echopedia.

## Goal
Preserve each person as a dignified historical record with voice, context, and provenance.

## Required sections
1. Identity Snapshot
   - English + 中文名 + romanized form
   - Era, geography, roles
2. Testaments / Voice
   - 2+ items preferred
   - Direct quote when available
   - If quote unavailable: "Attributed testimony summary" label required
   - Include date/period, context, source note for each item
3. Historical/Community Context
   - Institutional setting
   - Historical moment
   - 2-6 linked entities (people/org/location)
4. Contributions and Legacy
   - 3+ concrete claims, each with source note
5. Source & Confidence
   - Tag claim confidence: High / Medium / Needs verification
   - Distinguish 1971-source layer from 2025 retrospective framing when relevant
6. Name Variants / Disambiguation
7. Contribution Invitation
   - Ask for memories, testimonies, photos, docs, corrections

## Source ladder
- Tier A: primary (writings, sermons, interviews, letters)
- Tier B: near-contemporary secondary records
- Tier C: retrospective commentary/commemoration

Do not discard Tier C memory; preserve it with clear labeling.

## Tone
- Respectful, specific, non-flattening
- Avoid reducing people to title-only stubs
- Preserve ambiguity visibly when evidence is incomplete
