# Historical Source Cluster Expansion (Operational Playbook)

Use this when a user asks to "read it, wikify it, expand, structure innovatively, ensure linking," then repeatedly says "continue."

## Goal
Transform one source artifact (PDF/book/dissertation) into a durable, navigable wiki mini-ecosystem.

## Recommended Page Topology

1. Hub page (the source itself)
2. Author/person core page
3. Primary institution/org pages
4. Historiography pages
   - timeline
   - source-critical notes
   - terminology/translation notes
   - primary-source extracts
5. Navigation pages
   - people network map
   - places & institutions index
6. Satellite entity pages
   - secondary people
   - locations
   - theological reference figures

## Expansion Sequence

Phase 1: Hub + author + top-level org links
Phase 2: Core entity web-out
Phase 3: Historiography toolkit
Phase 4: Network/index pages
Phase 5: Additional entities and disambiguation

## Link Discipline

- Prefer `[[wiki-links]]` across the cluster.
- Ensure first mention of each key entity is linked.
- Add backlinks from satellites to hub page and at least one sibling page.

## Naming and Identity Discipline

- Keep Chinese characters + romanized form for Chinese-name entities.
- If multiple romanization spellings appear, designate one canonical page and add variant note.

## Reliability Loop (every phase)

1. Create/patch pages.
2. Run broken-link scan.
3. Fix all unresolved references.
4. Only then report completion for that phase.

## Tone/Workflow Expectation

When the user asks to continue, execute directly in iterative phases; do not pause for permission between phases unless scope/risk changes materially.
