# Echo System 3.0

**Version**: 3.0  
**Status**: Active Development  
**Last Updated**: 2026-06-23

## Overview

Echo System 3.0 is an advanced, layered knowledge and governance architecture designed for compounding intelligence through hierarchical autonomy.

It serves as the operating system for the **Echo System**, supporting TAHS (Taiwanese American Historical Society) and Echopedia.

## Core Active Profiles

As of June 2026, the following profiles are considered active:

- **echohsu** (main)
- **historian**
- **archivist**
- **content**
- **videoforge**
- **orchestrator**
- **echonomics** (intentionally isolated)

All other previously existing profiles have been archived.

## Core Layers

| Layer | Name | Primary Function |
|-------|------|------------------|
| 0 | Governance Layer | Meta-governor & Orchestrator |
| 1 | Semantic Layer | Persistent structured knowledge |
| 2 | Episodic & Relational Layer | Context, memory, and knowledge graph |
| 3 | Procedural Layer | Skills, workflows, and automation |
| 4+ | Verification Protocol | Accuracy and integrity enforcement |

## Key Principles

- **Compounding Intelligence** — Every layer improves over time.
- **Hierarchical Autonomy** — Clear separation of concerns with strong governance.
- **Layer 4+ Verification** — No task is considered complete without verification.
- **Provenance & Dignity** — All knowledge maintains source integrity.

## Current Focus Areas

- GBrain integration as the active memory layer
- Echopedia as the canonical historical record
- Agent fleet specialization and automation
- Identity governance and canonicalization
