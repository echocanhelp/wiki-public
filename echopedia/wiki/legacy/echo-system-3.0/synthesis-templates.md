# GBrain Synthesis Templates

**Version**: 0.1  
**Last Updated**: 2026-06-23

## 1. Entity Timeline

**Use when**: User asks about the history or development of a person or organization.

**Output Structure**:
- Brief identity summary
- Chronological key events (with sources)
- Notable relationships
- Current status (if known)

**Example Query**:
"Create a timeline for Wang Gui-Rong (王桂榮)"

---

## 2. Comparison

**Use when**: User wants to compare two or more entities.

**Output Structure**:
- Side-by-side comparison table
- Key similarities
- Key differences
- Sources

**Example Query**:
"Compare Lien-Hwa Chow and Choan-Seng Song"

---

## 3. Relationship Map

**Use when**: User wants to understand connections around a person or topic.

**Output Structure**:
- Central entity
- Direct connections (people, organizations, events)
- Relationship types
- Sources

**Example Query**:
"Show key relationships for the Taiwan Center Foundation"

---

## 4. Verified Summary

**Use when**: User wants a concise, source-backed overview.

**Output Structure**:
- 3–5 bullet points
- Each point includes source link
- Confidence level (High / Medium / Low)
- Verification status

**Example Query**:
"Give a verified summary of Echopedia's identity governance"

---

## 5. Open Questions

**Use when**: User wants to understand what is still unknown or needs research.

**Output Structure**:
- Known facts
- Open questions
- Suggested next research steps
- Related GBrain pages

**Example Query**:
"What do we still need to verify about [person]?"

---

## Usage Notes

- Always prefer GBrain data first
- Include source links where possible
- Flag unverified or low-confidence information
- Use "Verified Summary" template when accuracy is critical
