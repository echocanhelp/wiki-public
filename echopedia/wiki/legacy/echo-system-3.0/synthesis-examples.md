# GBrain Synthesis Examples

**Version**: 0.1  
**Last Updated**: 2026-06-23

## Example 1: Entity Timeline

**Template**: Entity Timeline  
**Query**: "Create a timeline for Wang Gui-Rong (王桂榮)"

**Expected Output Structure**:
- Brief identity
- Key events with dates and sources
- Notable relationships
- Current status

---

## Example 2: Comparison

**Template**: Comparison  
**Query**: "Compare Lien-Hwa Chow and Choan-Seng Song"

**Expected Output Structure**:
- Side-by-side table
- Key similarities
- Key differences
- Sources

---

## Example 3: Relationship Map

**Template**: Relationship Map  
**Query**: "Show key relationships for the Taiwan Center Foundation"

**Expected Output Structure**:
- Central entity
- Connected people and organizations
- Relationship types
- Sources

---

## Example 4: Verified Summary

**Template**: Verified Summary  
**Query**: "Give a verified summary of Echopedia's identity governance"

**Expected Output Structure**:
- 3–5 bullet points with sources
- Confidence level per point
- Verification status

---

## Example 5: Open Questions

**Template**: Open Questions  
**Query**: "What do we still need to verify about Ken Wu (吳兆峯)?"

**Expected Output Structure**:
- Known facts
- Open questions
- Suggested next steps
- Related GBrain pages

---

## Usage Tip

When using these templates, always start with:
> "Using GBrain data, [template name] for [entity/topic]"

This encourages brain-first behavior and consistent output quality.
