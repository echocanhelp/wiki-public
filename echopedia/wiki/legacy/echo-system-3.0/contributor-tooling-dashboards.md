# Contributor Tooling & Dashboards

**Status**: Design Phase  
**Version**: 0.1  
**Last Updated**: 2026-06-23

## Goal

Provide contributors with better tools and visibility when working with Echopedia and GBrain.

## Key Needs

- Easy way to see what needs work (missing pages, outdated content)
- Simple interfaces for proposing changes
- Visibility into ingestion waves and identity status
- Basic dashboards for common tasks

## Proposed Features

### 1. Basic Dashboard
- List of open ingestion waves
- Identity audit summary
- Recent GBrain activity

### 2. Contribution Tools
- Template-based page creation
- One-click proposal generation (linked to Feedback Loop)
- Simple search across Echopedia + GBrain

### 3. Status Indicators
- Visual flags for pages needing enrichment
- Verification status on person pages

## Recommended Starting Point

Start with a simple internal dashboard (not public) focused on:
- Ingestion wave status
- Identity audit results
- Quick links to common tasks
