# Echopedia Person Recordation Framework（Echopedia 人物記錄框架）

This framework defines how person pages should be built so each life is preserved with voice, context, and verifiable sources—not just a short bio.

## Core Vision
A person page should read like a respectful historical record:
1. **Who this person is** (identity and role)
2. **What this person did** (work and impact)
3. **How this person understood their work** (testament/voice)
4. **Why this matters historically** (community context)
5. **How we know** (source provenance)

## Required Structure for Person Pages

### 1) Identity Block
- Full name in English + Chinese characters + romanized form
- Role labels (pastor, organizer, educator, scholar, etc.)
- Era and geography (e.g., 1968–1985, Los Angeles)

### 2) Testament Block (Most Important)
- First-person quote(s), letter excerpts, sermon lines, interview fragments, or published statement
- If direct quote is unavailable, add **Attributed Testimony Summary** with explicit source note
- Each testimony item includes:
  - Date (or estimated period)
  - Context (speech, preface, interview, sermon, publication)
  - Citation line

### 3) Community Context Block
- Institutional setting (church, association, school, movement)
- Historical moment (migration wave, founding phase, transition period)
- Relationship network (2–6 linked people/org pages)

### 4) Contributions & Legacy Block
- Concrete contributions (founded, led, wrote, organized, mentored)
- Enduring influence (what changed because of this person)
- Intergenerational relevance (why younger readers should care)

### 5) Source & Confidence Block
- Source list with provenance tags:
  - Primary source (A)
  - Near-contemporary secondary source (B)
  - Retrospective commentary (C)
- Confidence note per major claim: High / Medium / Needs verification

## Source Ladder (for Respectful Accuracy)
- **Tier A**: direct writings, sermons, interviews, letters, archival documents
- **Tier B**: contemporaneous publications and organizational records
- **Tier C**: later recollections, commemorative essays, retrospective framing

Rule: do not erase emotional/personal testimony just because it is retrospective; preserve it and label it clearly.

## Contribution Features That Inspire Public Participation

### “Add a Memory” Path
Each person page should end with a contribution invitation:
- Family memory
- Colleague testimony
- Photo/document donation
- Corrections and name variants

### “Recognition Timeline”
Use short timeline entries so contributors can add one event at a time.

### “Voice Snippets”
Collect short, cited quotations that reveal personal convictions and style.

## Editorial Ethics
- Preserve dignity; avoid reducing people to institutional titles only.
- Distinguish fact, interpretation, and commemoration.
- Keep uncertain details visible but labeled (do not silently delete ambiguity).
- Name variants should be preserved with disambiguation notes.

## Person Depth Upgrade Addendum (v2)
For post-ingestion upgrade waves, person pages should additionally include:
- Historical Significance block
- Evidence Coverage Summary (totals + year spread)
- Context Highlights anchored to representative source links

This addendum complements (does not replace) the original testament-centered structure.
